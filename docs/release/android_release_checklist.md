# Androidリリースチェックリスト

## コード・依存関係

- [ ] Unity Editor、Packages、Google Playプラグインの対応バージョンを固定・確認した（Unity IAP 5.4.4 / Billing 9.0.0を含む）。
- [ ] `GooglePackages`を含む依存関係をクリーン環境で解決できる。
- [ ] IAP商品ID、商品種別、価格、サブスクリプション期間がPlay Consoleと一致する。
- [ ] Android購入、復元、キャンセル、返金、期限切れ、再インストールをストア状態で確認した。
- [ ] 16KBページサイズ対応を実AABとネイティブ依存関係で確認した。

## Androidビルド

- [ ] applicationId、versionName、versionCodeを確認した。
- [ ] minSdk、targetSdk、compileSdkが今回のPlay要件とUnity互換表を満たす（2026年8月31日以降の更新提出はtarget API 36以上）。
- [ ] ARM64を含むAABを生成した。
- [ ] Release設定、難読化、Manifest、依存関係のマージ結果を確認した。
- [ ] AABをローカルで検査し、デバッグ署名でないことを確認した。

## 署名

- [ ] Play App Signingの状態をPlay Consoleで確認した。
- [ ] upload keyの存在とaliasを安全な環境で確認した。
- [ ] SHA-1/SHA-256を取得し、Play Console登録証明書と照合した。
- [ ] keystore、パスワード、サービスアカウントJSONをGitやログに出していない。
- [ ] AABの証明書フィンガープリントを確認した。

## 実機テスト

- [ ] Android 13以降で初回通知権限、通知チャンネル、再起動後通知を確認した。
- [ ] 起動、主要画面遷移、Androidバックボタン、予測型バックを確認した。
- [ ] 縦向き、狭い画面、大画面、再起動、プロセス再生成を確認した。
- [ ] データ保存、削除、再インストール後の購入状態を確認した。
- [ ] 広告表示、広告削除、同意フォーム、ネットワーク不通時を確認した。

## ローカライズ

- [ ] 日本語表示、フォント、文字切れ、端末の言語設定を確認した。
- [ ] 英語対応を提供する場合、ストア説明とアプリ内文言を確認した。
- [ ] 日付、曜日、タイムゾーン、月末のサブスクリプション表示を確認した。

## 権限・プライバシー

- [ ] 最終マージManifestの権限を一覧化し、不要な権限を削除した。
- [ ] INTERNET、通知、広告ID、写真・ファイル、カメラの実使用を確認した。
- [ ] Privacy Policy URL、利用規約、問い合わせ導線が本番URLで開く。
- [ ] UMP同意、広告SDK、端末情報、購入情報の取り扱いを確認した。

## Data safety

- [ ] Play ConsoleのData safety回答を現行コード、SDK、プライバシーポリシーと照合した。
- [ ] 収集、共有、暗号化、削除要求、アカウント関連の各回答を確認した。
- [ ] SDK由来の広告ID、診断情報、課金情報の扱いを確認した。

## ストア掲載情報

- [ ] アプリ名、アイコン、スクリーンショット、説明、対象地域を確認した。
- [ ] プライバシーポリシーURL、コンテンツレーティング、審査メモを確認した。
- [ ] アプリのアクセス要件とテストアカウントを準備した。
- [ ] versionCode、対象API、リリースノートを確認した。

## 課金・広告

- [ ] Google Play Billingの商品状態とUnity IAPの商品定義を照合した。
- [ ] 新規購入、復元、別端末、キャンセル、返金、期限切れを検証した。
- [ ] 広告ユニット、広告削除状態、テスト広告、本番広告を区別した。
- [ ] UMPの地域別同意フローと広告表示前の初期化順序を確認した。

## Google Play提出前確認

- [ ] 内部テストまたはクローズドテストへAABをアップロードした。
- [ ] Play Consoleが受け付けるtarget API、署名、versionCodeである。
- [ ] Pre-launch report、クラッシュ、ANR、互換性警告を確認した。
- [ ] Data safety、コンテンツレーティング、対象地域、商品、掲載情報を確定した。
- [ ] 承認済みのリリース手順とロールバック手順を記録した。
